# Inscription en tant qu'agence

Kalechap permet aux **agences de placement** (agences de recrutement, sociétés de services, etc.) de s'inscrire avec un statut spécifique pour gérer leurs offres et bénéficier de fonctionnalités adaptées.

---

## 1. Différence avec une inscription individuelle

| **Inscription individuelle** | **Inscription agence** |
|---|---|
| Compte personnel pour un prestataire seul | Compte professionnel pour une structure |
| Pas de nom d'agence | Nom d'agence requis |
| Abonnement Gratuit suffisant pour débuter | Nécessite l'abonnement VIP pour activer les fonctionnalités |

---

## 2. Conditions préalables

Avant de vous inscrire en tant qu'agence, assurez-vous d'avoir :

- Un **nom d'agence** (nom de votre structure)
- Un **numéro Wave** valide (pour les transactions)
- Les **informations légales** de votre agence (si nécessaire)

---

## 3. Étapes d'inscription

### Étape 1 : Créer un compte standard

Suivez d'abord la procédure d'[Inscription](inscription.md) standard pour créer votre compte. Vous recevrez un compte personnel comme tout utilisateur.

### Étape 2 : Accéder à votre profil

Une fois connecté, ouvrez le menu latéral (bouton hamburger) et passez dans l'onglet **Prestataire**, puis cliquez sur **Profil**.

![Accès au profil](images/menu_prestataire.png)

### Étape 3 : Activer le mode Agence

Dans la page de votre profil, vous trouverez une section **Inscription en tant qu'agence**. Remplissez les champs suivants :

- **Nom de l'agence** : le nom officiel de votre structure
- **Genre** : homme / femme (pour le représentant légal)

![Inscription agence](images/placeholder_agency_registration.png)

### Étape 4 : Valider l'inscription

Appuyez sur le bouton **Enregistrer** ou **S'inscrire en tant qu'agence** pour soumettre votre demande.

> [!NOTE]
> L'inscription en tant qu'agence sera enregistrée, mais vous devrez **souscrire au plan VIP** pour activer les fonctionnalités de prestataire pour votre agence.

### Étape 5 : Souscrire au plan VIP

Redirigé vers la page de [Souscription](subscription.md), choisissez le plan **VIP** et procédez au paiement Wave pour activer votre compte agence.

### Étape 6 : Vérification du statut

Une fois l'inscription agence validée, vous verrez sur votre profil :

- Un badge **Agence** ou **Agence vérifiée**
- Le nom de votre agence affiché sur vos offres de service
- Des options supplémentaires dans le menu prestataire

![Badge Agence sur le profil](images/placeholder_agency_badge.png)

---

## 4. Fonctionnalités spécifiques aux agences

| Fonctionnalité | Détail |
|---|---|
| **Badge Agence** | Vos offres affichent un badge "Agence" pour rassurer les clients |
| **Code de parrainage** | Code spécial pour le réseau d'agence ([Code de parrainage](code-parrainage.md)) |
| **Plan VIP requis** | Accès complet aux fonctionnalités de gestion d'offres |
| **Vérification** | Statut "Vérification en attente" puis "Vérifiée" après validation |

---

## 5. Questions fréquentes

**Puis-je passer d'un compte individuel à un compte agence ?**
Oui, il suffit d'ajouter le nom de votre agence dans les paramètres de votre profil comme décrit ci-dessus.

**Mon abonnement Gratuit ou Standard suffit-il pour une agence ?**
Non, le statut agence nécessite l'abonnement VIP pour activer les fonctionnalités complètes.

**Puis-je avoir plusieurs agences avec un seul compte ?**
Non, un compte correspond à une seule agence.
