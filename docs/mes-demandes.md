# Suivre mes demandes

Après avoir envoyé une demande de service (voir [Demander un service](service-request.md)), vous pouvez suivre l'état de vos demandes depuis votre tableau de bord.

---

## 1. Accéder à "Mes demandes"

1. Ouvrez le menu latéral (bouton hamburger) en haut à gauche
2. Restez dans l'onglet **Demandeur** (par défaut)
3. Cliquez sur **Mes demandes**

![Lien Mes demandes dans le menu](images/placeholder_my_requests_menu.png)

---

## 2. Comprendre l'écran de suivi

Vous voyez la liste de **toutes les demandes que vous avez envoyées**, avec les informations suivantes pour chacune :

| Élément | Description |
|---|---|
| **Service demandé** | Nom du service et nom du prestataire |
| **Date d'envoi** | Quand vous avez fait la demande |
| **Statut** | L'état actuel de votre demande (voir ci-dessous) |
| **Budget** | Le montant que vous avez proposé |

![Écran Mes demandes](images/placeholder_my_requests.png)

---

## 3. Les différents statuts d'une demande

| Statut | Signification |
|---|---|
| ⏳ **En attente** | Votre demande a été envoyée, le prestataire ne l'a pas encore traitée |
| ✅ **Acceptée** | Le prestataire a accepté votre demande. Vous pouvez le contacter via les coordonnées affichées |
| ❌ **Refusée** | Le prestataire a décliné votre demande |
| ✅ **Terminée** | Le prestataire a marqué le service comme effectué. Vous pouvez alors laisser une évaluation |
| ❌ **Annulée** | Vous avez annulé la demande |

---

## 4. Annuler une demande

Tant que le prestataire n'a pas accepté la demande, vous pouvez l'annuler :

1. Ouvrez la demande dans **Mes demandes**
2. Appuyez sur le bouton **Annuler la demande**
3. Confirmez l'annulation

> [!WARNING]
> Une fois que le prestataire a accepté la demande, vous ne pouvez plus l'annuler depuis l'application. Contactez le prestataire directement si besoin.

---

## 5. Après acceptation

Lorsque le prestataire accepte votre demande, vous voyez :

- Le numéro de téléphone du prestataire (pour le contacter via WhatsApp, appel ou SMS)
- Son adresse e-mail (si renseignée)
- Le statut passe à **Acceptée**

> [!TIP]
> Contactez rapidement le prestataire pour convenir des détails de la prestation (date, heure, lieu précis).

---

## 6. Après la fin du service

Une fois que le prestataire marque le service comme **Terminé**, vous recevez une notification dans l'application.

Profitez-en pour [laisser une évaluation](evaluations.md) et partager votre expérience !
