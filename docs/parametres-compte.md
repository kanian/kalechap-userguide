# Paramètres du compte

Gérez vos informations personnelles, votre mot de passe et les préférences de votre compte Kalechap.

---

## 1. Accéder aux paramètres

1. Ouvrez le menu latéral (bouton hamburger) en haut à gauche
2. Cliquez sur **Compte** dans le menu (dans l'onglet Demandeur)

![Lien Compte dans le menu](images/placeholder_account_menu.png)

---

## 2. Modifier vos informations personnelles

Dans la section **Compte**, vous pouvez modifier :

- **Nom de famille**
- **Prénom**
- **Numéro de téléphone**
- **Adresse e-mail**

Pour modifier :

1. Saisissez les nouvelles valeurs dans les champs correspondants
2. Appuyez sur le bouton **Sauvegarder** ou **Enregistrer**
3. Les modifications sont appliquées immédiatement

![Écran des paramètres du compte](images/placeholder_account_settings.png)

> [!NOTE]
> Votre numéro de téléphone est votre identifiant principal. Si vous le changez, vous devrez utiliser le nouveau numéro pour vous connecter.

---

## 3. Changer votre mot de passe

Vous pouvez changer votre mot de passe à tout moment :

1. Dans la page **Compte**, repérez la section **Mot de passe**
2. Saisissez votre **mot de passe actuel**
3. Saisissez votre **nouveau mot de passe**
4. Confirmez le nouveau mot de passe
5. Appuyez sur **Changer le mot de passe**

> [!WARNING]
> Choisissez un mot de passe fort (minimum 8 caractères, avec lettres, chiffres et symboles). Ne le partagez avec personne.

---

## 4. Mot de passe oublié (Récupération de compte)

Si vous avez oublié votre mot de passe :

1. Sur l'écran de [connexion](connexion.md), appuyez sur **Mot de passe oublié ?**
2. Saisissez votre **numéro de téléphone** ou votre **adresse e-mail**
3. Suivez les instructions pour réinitialiser votre mot de passe

> [!IMPORTANT]
> La récupération de compte par e-mail n'est possible que si vous avez renseigné une adresse e-mail lors de l'inscription. C'est pourquoi il est fortement recommandé d'ajouter votre e-mail dans les paramètres du compte.

---

## 5. Supprimer votre compte

Si vous souhaitez supprimer définitivement votre compte Kalechap :

> [!WARNING]
> La suppression de compte est irréversible. Toutes vos données (profil, offres de service, demandes, évaluations) seront définitivement effacées.

1. Dans la page **Compte**, descendez jusqu'à la section **Supprimer mon compte**
2. Appuyez sur le bouton **Supprimer mon compte**
3. Confirmez la suppression dans la boîte de dialogue

---

## 6. Questions fréquentes

**J'ai changé mon numéro de téléphone, comment récupérer mon compte ?**
Si vous avez renseigné une adresse e-mail, vous pouvez l'utiliser pour vous connecter ou réinitialiser votre mot de passe. Sinon, contactez le support.

**Puis-je utiliser la même adresse email pour plusieurs comptes ?**
Non, chaque adresse e-mail ne peut être associée qu'à un seul compte Kalechap.

**Que se passe-t-il si je supprime mon compte ?**
Toutes vos offres de service, demandes, évaluations et informations personnelles sont supprimées. Vos clients ne pourront plus vous contacter via la plateforme.
