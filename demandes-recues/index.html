    Gérer les demandes reçues

    En tant que prestataire, vous recevez des demandes de services de la part des utilisateurs. Voici comment les consulter et y répondre.

    1. Accéder aux demandes reçues

    1. Ouvrez le menu latéral (bouton hamburger) en haut à gauche
    2. Passez dans l'onglet Prestataire
    3. Cliquez sur Demandes reçues

    [!IMPORTANT] L'onglet Prestataire est accessible à tous les utilisateurs ayant un abonnement actif (Gratuit, Standard, Pro ou VIP).

    2. La liste des demandes

    L'écran affiche toutes les demandes que les clients vous ont envoyées, avec :

    Information Description
    Client Nom et prénom du demandeur
    Service concerné Quelle offre de service est demandée
    Date de réception Quand la demande a été soumise
    Budget proposé Le montant que le client propose
    Statut En attente, Acceptée, Refusée, Terminée

    3. Consulter les détails d'une demande

    Cliquez sur une demande pour voir :

    • Le résumé de la demande (titre donné par le client)
    • La description détaillée du besoin
    • Le budget proposé par le client
    • Les coordonnées du client (numéro de téléphone, email)

    4. Répondre à une demande

    Accepter une demande

    Si le service vous convient et que vous êtes disponible :

    1. Ouvrez la demande
    2. Appuyez sur le bouton Accepter
    3. Le statut passe à Acceptée
    4. Le client voit votre numéro de téléphone pour vous contacter

    Refuser une demande

    Si vous ne pouvez pas ou ne voulez pas réaliser ce service :

    1. Ouvrez la demande
    2. Appuyez sur le bouton Refuser
    3. La demande est marquée comme Refusée
    4. Le client en est informé

    [!NOTE] Vous n'avez pas besoin de fournir de motif de refus, mais un retour constructif est toujours apprécié.

    5. Marquer un service comme terminé

    Une fois que vous avez réalisé la prestation :

    1. Ouvrez la demande acceptée
    2. Appuyez sur le bouton Marquer comme terminé
    3. Le statut passe à Terminée
    4. Le client peut alors laisser une évaluation sur votre service

    [!TIP] Pensez à demander au client de laisser un avis après la prestation — les bonnes évaluations améliorent votre visibilité !

    6. Conseils pour bien gérer vos demandes

    • ✅ Répondez rapidement — plus vous répondez vite, plus le client sera satisfait
    • ✅ Soyez clair — si vous acceptez, confirmez les détails par téléphone ou message
    • ⚠️ Ne partagez pas vos coordonnées avant d'avoir accepté — tout passe par la plateforme jusqu'à l'acceptation
